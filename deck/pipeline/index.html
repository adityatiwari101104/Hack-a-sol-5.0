The verification layer, gate by gate

Cheapest checks first; the first failure decides. Gates a–d are plain code, gate e is a ladder where later steps can only rescue a sentence, never let a failing one through. Ablation: without gate b, 18 wrong “current law” sentences reach users; without the number checks, 7; without gate e, 90.
